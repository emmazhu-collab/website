# Blog 4: Two Kinds of Gas

## Question and method

Which fuel became more expensive after inflation, and which had larger monthly price changes? Four figures connect nominal gasoline prices, nominal natural gas prices, real-price indexes, and the distribution of monthly real-price changes. This separates long-term price levels from short-term variability.

## Data and sources

The saved inputs were downloaded through the FRED API on October 5, 2026. They cover January 2000–August 2026, with 320 monthly rows per series.

| Source file | FRED series and original units |
| --- | --- |
| `data/source/gasoline-monthly.csv` | [GASREGW](https://fred.stlouisfed.org/series/GASREGW): EIA weekly regular gasoline retail prices including taxes, dollars per gallon |
| `data/source/natural-gas-monthly.csv` | [DHHNGSP](https://fred.stlouisfed.org/series/DHHNGSP): EIA daily Henry Hub spot prices, dollars per million BTU |
| `data/source/cpi-monthly.csv` | [CPIAUCNS](https://fred.stlouisfed.org/series/CPIAUCNS): BLS monthly CPI-U, all items, U.S. city average, 1982–1984 = 100 |
| `data/source/download-date.csv` | Original download date |

The API request uses `frequency = "m"` and `aggregation_method = "avg"` for both fuels; CPI is already monthly. These are saved monthly API results, not the original daily or weekly observations. None of the series is seasonally adjusted.

Natural gas is missing in March 2004 and CPI in October 2025. The code leaves missing values blank. There are 318 months with both real-price levels and 315 matched monthly changes. A missing month also makes the following month's percentage change unavailable; changes never jump across a gap.

## Reproduce the article

1. Open `studentname-website.Rproj` in RStudio.
2. Install missing packages once:

   ```r
   install.packages(c("tidyverse", "fredr", "knitr", "rmarkdown"))
   ```

3. Open `blog/posts/post4/index.qmd` and click **Render**.

Render calls `code/analysis.R` and recreates the processed data, summaries, four figures, and article numbers. After installing packages, this needs no API key or internet connection. The webpage displays only prose and graphs and is written to `docs/blog/posts/post4/` by the website project.

To run the analysis alone, start from the website project folder:

```r
setwd("blog/posts/post4")
source("code/analysis.R")
```

Run `setwd()` only once; skip it if already in `post4`. From a terminal in `post4`, run `Rscript code/analysis.R`.

## Calculations

- Real price = nominal price × August 2026 CPI ÷ that month's CPI.
- Real-price index = 100 × real price ÷ January 2000 real price.
- Monthly change = 100 × (this month's real price ÷ previous month's real price − 1).
- Average absolute change = mean of the absolute monthly changes. This measures movement size without letting rises and falls cancel.

The code uses identical complete month pairs for both fuels' volatility, correlation, and same-direction comparisons. It also saves the standard deviation of changes as another measure of spread. Same direction means the two changes have the same sign; two zero changes count as the same sign.

The first three figures show the level and inflation-adjusted paths. The fourth uses percentage changes to compare variability across different price units. The box shows the middle 50% of changes, its line is the median, and points beyond the whiskers identify unusually large changes under the boxplot rule.

Every result and figure is calculated and saved with R; none is manually copied from the Console. Rebuilding from source inputs alone was checked, including the article's inline calculations. ## Optional fresh download

Set your own `FRED_API_KEY` in your local `.Renviron` and restart R. Keep the key out of scripts and Git. From `post4`, run `source("code/download.R")` to request the three series for the same date range. New CSVs and their download date go into `data/downloads/YYYY-MM-DD/`.

FRED may revise data. Review a new download before replacing `data/source/`, then rerun the analysis and check the article's dates and interpretation. Use the included inputs to reproduce this version. The optional API download was separated from the existing code but was not rerun during this review.

## Limits

Henry Hub is wholesale, not a household heating bill. Different units prevent a direct dollar-price comparison. Index levels depend on the starting month. Missing observations reduce the change sample, and the data are not seasonally adjusted. These are descriptive results, not evidence about causes or a forecast of future prices.
