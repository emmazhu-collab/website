Simulation, Bootstrap Confidence Intervals, and Hypothesis Testing

simulation
statistical inference
Published

October 27, 2026

How can one sample tell us about a population? Imagine checking a measuring instrument. Its error is the reported length minus the actual length. The sample mean estimates its average error, but another sample may give a different value.

Can we learn from just one sample?

Suppose independent errors come from a normal population with a mean of 0.4 mm and a standard deviation of 2 mm. In this simulation, we know the true mean; with real data, we would not. Our 100 readings have a mean of 0.477 mm. How much might it change in another sample?

With one sample, we cannot see how the mean would change. Instead, draw from the sample with replacement, so a value can appear more than once. A resample of 2, 4, 5, 7, 8 might be 2, 2, 5, 7, 8: 2 repeats and 4 is left out. This is the bootstrap.

The code below draws 100 values with replacement, finds their mean, and repeats this 2,000 times. Without replacement, drawing all 100 would only rearrange the same values, so the mean would not change.

set.seed(6408)
x <- rnorm(100, mean = 0.4, sd = 2)
bootstrap_means <- function(x, B = 2000) {
  n <- length(x)
  draws <- matrix(x[sample.int(n, n * B, replace = TRUE)], nrow = n)
  colMeans(draws)
}
ci_from <- function(z, level = 0.95) {
  alpha <- 1 - level
  unname(quantile(z, c(alpha / 2, 1 - alpha / 2)))
}
boot <- bootstrap_means(x)
ci_from(boot)

The bootstrap distribution contains 2,000 means from our resamples. It helps estimate how the mean might vary across new samples. A 95% interval keeps the middle 95% of these means. Before changing the control, predict: why is a 99% interval wider?

Figure 1. One sample, 2,000 bootstrap resamples. Black marks the sample mean; orange dashed lines mark the selected interval endpoints.

The 95% interval is [0.066, 0.893] mm. Switch to 99% in Figure 1. The interval widens to include more values. It describes uncertainty about the mean, not individual errors. More resamples make it steadier, but add no new population data.

Figure 1 gives one interval. Does this method work over many samples? If we repeat the experiment, should every 95% interval contain the true mean? No. About 95% should. We can check because we know the true mean, 0.4 mm: each time, draw a new sample, then bootstrap within it.

What does 95% confidence really mean?

The code repeats these steps 2,000 times and checks whether each interval contains 0.4 mm. The share that includes the true mean estimates coverage. This example shows 95%; the full script also calculates 90% and 99%.

set.seed(6409)
covered <- logical(2000)
for (i in seq_along(covered)) {
  fresh <- rnorm(100, mean = 0.4, sd = 2)
  ci <- ci_from(bootstrap_means(fresh))
  covered[i] <- ci[1] <= 0.4 && 0.4 <= ci[2]
}
mean(covered)

Figure 2 shows the first 50 intervals, while coverage uses all 2,000 simulations. The black line marks the true mean. Why do some 95% intervals miss it?

Figure 2. Blue solid lines contain the true mean; orange dashed lines miss it. Black marks 0.4 mm.

Most intervals cross the black line, but a few orange ones miss. Of 2,000 intervals, 1,901 contain the true mean: coverage is 95.05%. Higher confidence gives wider intervals that capture the mean more often.

A 95% confidence interval either contains the true mean or it does not. The 95% refers to how the procedure performs over many repeated samples; it is not the probability that this particular, already-calculated interval contains the mean. Simulated coverage may differ from 95%, and bootstrap intervals are estimates.1

The interval shows which average errors are plausible. Now suppose the manufacturer says the average error is zero. Our sample mean is 0.477 mm. Could this difference happen by chance?

Is the instrument actually biased?

Assume the manufacturer’s claim is true. We test H₀: μ = 0 against H₁: μ ≠ 0, using the sample from Figure 1. H₀ says the average error is zero; H₁ says it is not. The t-statistic measures how far the sample mean is from zero, in standard-error units:

\[t = \frac{\bar{x}-0}{s/\sqrt{100}},\]

Here, \(s\) is the sample standard deviation. Our statistic is 2.165. Could it happen if H₀ were true? We simulate 20,000 samples with a mean of zero and calculate the same statistic.

In R, I use the simulated t-statistics to build the null distribution and calculate a two-sided p-value:

t_stat <- function(y) mean(y) / (sd(y) / sqrt(length(y)))
observed_t <- t_stat(x)
set.seed(6410)
null_t <- replicate(20000, t_stat(rnorm(100, 0, 2)))
critical <- quantile(abs(null_t), 0.95, type = 1)
p_value <- (sum(abs(null_t) >= abs(observed_t)) + 1) / (length(null_t) + 1)
p_value

These t-statistics show what we might see if H₀ were true. The p-value estimates the chance of getting a result this far from zero or farther if H₀ is true. Orange marks these results; purple marks rejection regions. Change α from 0.05 to 0.01. Why does the decision change while the p-value stays the same?

Figure 3. The histogram shows 20,000 null t-statistics. Purple shading marks rejection regions; orange bars mark statistics at least as extreme as observed. Solid and dotted black lines mark the observed t and its opposite.

At α = 0.05, reject when |t| > 1.983. The p-value is 0.0328: about 3.3% of results are this extreme under H₀. It is not the chance that H₀ is true. The “+1” adjustment keeps the estimate above zero. Since p < 0.05, we reject H₀.

At α = 0.01, the purple regions move farther into the tails, but the p-value stays 0.0328. The new cutoff is 2.633, so we do not reject H₀. This does not prove zero bias.

Taken together, the three simulations show what we can learn from one sample and where its limits are. Bootstrap resampling helps us measure uncertainty, repeated samples show how often confidence intervals capture the true mean, and the null simulation helps us test the zero-mean claim. Here, the 95% bootstrap interval excludes zero, and the simulated test rejects a zero mean at the 5% level. Both point to a positive average error, though the methods may not always agree. A single estimate is more useful when we also ask how it might change across samples.

The controls use results calculated in R, so no R server is needed. To run the simulation, download simulation.R and simulation_config.R. Keep both files in a code/ folder.
