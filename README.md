## Blog 3: Education and Unemployment

This post uses IPUMS CPS Basic Monthly January data for 2020–2026 and the person weight `WTFINL`. Three figures show unemployment over time, unemployment within age groups, and employment status by education. The last figure includes people outside the labor force, so it adds information beyond unemployment rates.

The trend and age panels use civilians ages 25–64 in the labor force. The status chart uses all civilian adults ages 25–64. Its unemployed share has a different denominator from an unemployment rate. The age comparison shows that the education gap remains within age groups, rather than being explained only by differences in age composition.

- `blog/posts/post3/index.qmd`: article.
- `blog/posts/post3/analysis.R`: weighted analysis and three figures.
- `blog/posts/post3/data/`: local CPS microdata and matching XML dictionary.
- `blog/posts/post3/results/`: rates by year, rates by age, and status shares by education.
- `blog/posts/post3/graph/`: the three saved figures.

### Replication instructions

Download the January Basic Monthly samples for 2020–2026 from [IPUMS CPS](https://cps.ipums.org/cps/), including `YEAR`, `MONTH`, `AGE`, `EDUC`, `EMPSTAT`, and `WTFINL`. Place the matching data and dictionary in `blog/posts/post3/data/` as `cps_00001.dat.gz` and `cps_00001.xml`. Raw microdata are not included in Git; readers need their own extract.

Open the website project in RStudio. Install `ipumsr` and `tidyverse` if missing. Copy this into the R Console to generate the tables and figures without rendering:

```r
source("blog/posts/post3/analysis.R", chdir = TRUE)
```

To update the webpage later, open `blog/posts/post3/index.qmd` and click **Render**. See the [Blog 3 README](blog/posts/post3/README.md) for data definitions, file paths, and full instructions.

## Blog 4: U.S. Energy Prices

This post compares gasoline and natural gas prices from January 2000 to August 2026 using FRED data collected with R. The first two figures show each fuel’s price history. The third compares inflation-adjusted changes from a common starting index, and the fourth compares monthly price swings. Together they show why a lower long-term price does not necessarily mean greater short-term stability. The takeaway connects these differences to planning costs for the fuel a business actually uses.

The article, `code/`, `data/`, `results/tables/`, `results/figures/`, and replication instructions are in [`blog/posts/post4/`](blog/posts/post4/README.md). ## Blog 5: Texas County Household Income

This post uses R and Census data to explore income differences across 254 Texas counties. It includes a Leaflet map, a saved tmap map, and a ggplot2 comparison of ten counties. The data are 2020–2024 ACS five-year estimates in 2024 dollars.

The [Blog 5 repository](https://github.com/emmazhu-collab/blog5) contains `code/analysis.R`, optional `code/download.R`, original data, processed data, and saved results. Its [README](https://github.com/emmazhu-collab/blog5/blob/main/README.md) documents sources, checks, and outputs.

### Replication instructions

Download the complete Blog 5 repository with **Code > Download ZIP**, unzip it, and open `blog5.Rproj`. Keep the code and data folders together. Use the R Console (`>`), not the Python Console (`>>>`). If needed, select **Session > Restart R**.

Install missing packages once in the R Console:

```r
install.packages(c("tidyverse", "sf", "tmap", "leaflet", "htmlwidgets", "tidycensus"))
```

Copy only the command below, without backticks, into the R Console and press Enter:

```r
source("code/analysis.R")
```

You can also open `code/analysis.R`, select all with **Command+A**, and click **Run**. Start from the first line. The working directory must be the main Blog 5 folder. The code uses tmap 4; its layer structure follows the DataCamp examples, with current palette and legend syntax.

This rebuilds the tables and maps from included inputs. It needs no Census key for normal reproduction. Static plots appear in Plots and the Leaflet map in Viewer. The saved files are in `results/tables/` and `results/figures/`. The interactive map uses saved county polygons and local support files, so no background tile key is needed.

To download fresh data, save your Census key locally as `CENSUS_API_KEY` in your user `.Renviron`, restart R, and run `source("code/download.R")` before the analysis. Do not put the key in code or Git.

**Terminal alternative:** from the Blog 5 folder, run `Rscript code/analysis.R`.

**Jupyter alternative:** use an R kernel and create the notebook in the Blog 5 folder. If necessary, install `IRkernel` in R and run `IRkernel::installspec(user = TRUE)`; this needs Jupyter installed and on the system path. In an R code cell, run:

```r
source("code/analysis.R")
income_leaflet
```

Press **Shift+Enter**. Use `income_map` or `comparison` in separate cells to display the static figures. See the Blog 5 README for setup details.
